# Server Manager 0.4.1

## Discord 알림

- 서버가 계속 실행되는 비치명적 오류는 개별 메시지를 보내지 않고 제어 패널의 오류 카운트에만 반영합니다.
- 실제 비정상 종료 시 종료 알림 하나에 **예외 이름·설명·Caused by**를 표시합니다. 스택 프레임과 Mixin 변환 목록은 제외하고 길이를 제한합니다.
- 크래시 리포트가 있으면 해당 보고서의 Description과 예외 연결을 우선 사용하고 기존 파일 첨부도 유지합니다. 봇에 파일 첨부 권한이 없어도 텍스트 요약은 제공합니다. 보고서가 없으면 종료 직전 30초 이내에 관찰한 오류를 참고 정보로 표시합니다. 오래된 오류를 종료 원인으로 단정하지 않습니다.
- 원격 종료 때는 오류 요약을 메모리에 고정하여 긴 파일 인계나 다음 실행 때문에 다른 오류로 바뀌지 않게 했습니다. 일반 오류 요약과 스택 파싱 결과는 디스크에 저장하지 않습니다.
- 비정상 종료 알림과 정상 종료 알림을 각각 설정할 수 있습니다. 시작 완료 알림은 그대로 제공합니다. 실제 친구에게 검증 메시지를 보내지 않았습니다.

## 저장 가능한 로그 필터

- 콘솔에서 **제외할 키워드·모드/로거**를 지정해 반복 메시지를 숨길 수 있습니다. DEBUG·TRACE에만 적용하거나 모든 수준에 적용할 수 있습니다.
- 이름을 붙여 저장·불러오기·삭제하고 전체 필터를 잠시 끌 수 있습니다. 설정은 **사용자·서버별**로 저장되며 같은 계정의 다른 브라우저에서도 유지됩니다. VIEWER도 자신의 화면 필터를 저장할 수 있습니다.
- 모드/로거 태그·패키지를 기준으로 일치시킵니다. Mixin 목록에서 모드가 단순히 언급된 프레임까지 숨기지 않습니다. 태그가 없으면 키워드를 사용하세요.
- 원본 로그와 오류 카운트는 유지합니다. 새 로그만 Worker에서 파싱하고 기존 가상화와 500ms 로딩 오버레이를 유지합니다. 필터 적용은 재파싱을 일으키지 않습니다.

## 업데이트

0.4.0 정식 설치는 기존 서명 자동 업데이트를 사용합니다. 게임 실행과 파일 인계가 끝난 뒤 적용하며 계정·패스키·월드·기존 설정을 보존합니다. 원격 크래시 파일 첨부에는 실행기 0.4.0 이상과 봇의 파일 첨부 권한이 필요합니다. 이번 수정은 Modrinth 설치·모드 전용 페이지·이진 탐색 디버깅을 포함하지 않으며 해당 예약 작업은 계속 남아 있습니다.
