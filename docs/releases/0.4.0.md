# Server Manager 0.4.0

BETA 개발분을 정식 릴리스로 전환했습니다. 관리 웹과 친구용 Mac·Windows 실행기를 함께 배포합니다.

## 이번 패치

- **콘솔에서 바로 채팅**: 일반 입력은 `say`로 전송합니다. `안녕하세요` → `say 안녕하세요`. 명령은 `/list`, `/stop`처럼 입력하세요. 중복 전송을 방지하고 실패 시 입력을 복원합니다.
- **Discord 시작 완료 알림**: 서버가 실제로 준비됐을 때 초록색 임베드를 한 번 보냅니다. 알림 규칙에서 켜고 끌 수 있고 기존 규칙은 기본 활성화됩니다.
- **서버별 자동 재시작 토글**: 기본 OFF. 예기치 않은 종료를 대상으로 하며 수동 중지 포함 옵션도 제공합니다. 무인 절전·명시적 재시작·관리 앱 종료는 제외합니다. 파일·클라우드 인계 이후 시작하며 15·30·60초 대기, 10분 동안 최대 3회로 반복 크래시를 제한합니다. 이번 재시작 취소를 지원합니다.
- **종료 이유와 크래시 리포트**: 정상 요청·절전·재시작·예기치 않은 종료와 종료 코드를 구분합니다. 해당 실행에서 새로 생성·변경된 크래시 리포트를 최대 8 MiB까지 Discord에 첨부합니다. 원격 첨부에는 0.4.0 실행기가 필요합니다. 오래된 리포트나 임의 경로·심볼릭 링크는 첨부하지 않습니다.
- **파일 전송 완료 화면 수정**: 완료 즉시 로딩 표시를 제거하고 확인 메시지는 3초 후 닫습니다. 늦게 도착한 실행기 상태가 로딩을 되살리던 문제를 수정했습니다.
- **UI 개선**: 진행 표시 주변 여백·단계·모바일 줄바꿈, 둥근 카드와 초록색 강조, 부드러운 짧은 전환을 적용했습니다. OS의 동작 줄이기를 존중하며 로그 가상화와 500ms 파싱 오버레이 규칙을 유지합니다. 파일 변경 불가 안내 중복도 제거했습니다.

## BETA 기간에 추가된 기능

- Vanilla·Paper·Fabric·Forge·NeoForge 선택과 공식 파일 검증, mrpack 가져오기.
- 별도 Mac/Windows 실행기, 초대 사용자의 패스키 등록·서버별 사용 허용과 실행 위치 선택.
- 친구용 GUI/CLI 설치판, Java 포함, 로그인 자동 대기와 서명 검증 자동 업데이트.
- 원래 위치의 기존 서버 폴더 연결·최초 가져오기와 변경 파일 전송 진행 표시.
- WebDAV 변경 파일 동기화와 실행기 간 인계, 공유 TCP 중계·서버별 A/SRV 도메인 설정.
- Discord 제어 패널의 인원·명단·업타임·오류 빈도와 역할별 시작·중지·재시작 권한.
- 서버별 30~60분 무인 절전(기본 OFF)과 실제 인원 재확인 후 정상 저장·종료.

## 업데이트와 설정

기존 BETA 설치는 서명된 0.4.0으로 자동 전환할 수 있습니다. 전환 후에는 정식 채널을 사용합니다. 관리 웹·실행기 모두 게임 실행과 파일 인계가 끝나야 업데이트를 적용합니다. 계정·패스키·월드·원래 폴더 경로를 유지합니다.

자동 재시작은 **서버 설정**에서, 시작 알림은 **계정과 보안 → Discord 봇 → 서버별 알림**에서 설정하세요. 크래시 리포트 전송에는 봇의 **파일 첨부** 권한이 필요합니다. 리포트에는 서버 경로와 모드 정보가 포함될 수 있습니다. 원격 종료 알림과 첨부는 변경 파일 인계가 끝난 뒤 전송합니다. 자동 재시작 대기는 관리 앱 종료 시 취소되지만 설정과 재시도 한도 기록은 유지됩니다.

## 검증 범위와 남은 작업

격리된 프로필·브라우저 모의 API·실제 로컬 프로세스로 검사하며 운영 월드나 실제 Discord 친구에게 검증용 메시지를 보내지 않습니다. Apple 공증/Windows Authenticode 서명은 제공하지 않으며 앱 업데이트 파일은 별도 Ed25519 서명을 검증합니다.

Modrinth 확장 설치·모드 전용 관리 페이지와 의존성 보존 충돌 이진 탐색은 아직 개발 중이며 이번 릴리스에서 완료된 기능으로 제공하지 않습니다. 같은 컴퓨터의 Minecraft 서버 동시 실행 확장은 후속 이슈 #1입니다.
