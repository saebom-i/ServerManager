## 선택한 모드에서 문제 원인 찾기

- **모드 · 문제 찾기** 탭을 추가했습니다. 모드 이름·ID·버전·활성 상태와 필수 의존성을 확인하고 검색할 수 있습니다. 파일 해시는 목록을 직접 불러올 때만 검사합니다.
- 선택 모드를 비활성화하기 전에, 그 모드에 의존해 함께 꺼지는 모드 목록을 보여줍니다. JAR는 삭제하지 않고 `.jar.disabled`로 보존하며, 이 화면에서 끈 파일은 같은 내용인지 확인한 뒤 다시 활성화할 수 있습니다.
- 의심 모드와 항상 유지할 메인 모드를 선택해 수동 이진 탐색을 시작할 수 있습니다. 메인 모드의 필수 의존성을 유지하고, 함께 켜야 하는 의심 모드는 묶어서 검사합니다.
- 먼저 전체 의심 모드를 켠 재현 시도와 모두 끈 비교 시도를 진행합니다. 사용자가 직접 접속·플레이한 뒤 **이번 시도 성공 / 이번 시도 실패 / 판정 불가**로 알려주면 다음 조합을 제안합니다. 원인 하나 또는 여러 모드의 재현 조합을 좁히고, 찾은 원인을 제외한 추가 탐색도 지원합니다.
- 실행 중 판정하면 저장 후 정상 종료를 요청합니다. 종료 및 파일 인계가 완료되기 전에는 다음 조합으로 넘어가지 않습니다. 크래시·에러 로그만으로 자동 실패 처리하지 않으며, 의존성 누락 로그는 원래 문제의 재현으로 세지 않도록 안내합니다.
- 시도 메모·현재 탐색 차수의 판정 수정·원본 로그 이력·중단·재개·원본 복귀를 제공합니다.

## 원본 파일과 실행기 보호

- 검사는 별도 폴더에 복사한 서버 런타임과 **매 시도 새 테스트 월드**로 진행합니다. 원본 월드를 복사하거나 열지 않습니다. 기존 월드에서만 발생하는 문제는 새 월드에서 재현되지 않을 수 있습니다.
- Mac·Windows 실행기는 같은 서버 권한과 기존 접속 주소를 유지하면서 검사 전용 폴더를 사용합니다. **원격 검사는 실행기 0.4.3 이상이 필요합니다.** 이전 실행기는 원본 폴더 보호를 위해 검사 실행을 거부합니다.
- 검사 중 운영 WebDAV 동기화·자동 재시작·무인 절전·업데이트 적용과 원본 설정/실행기 변경을 막습니다. 정상 종료와 파일 인계 후 검사를 일시 중단하거나 종료하면 원본 폴더로 돌아갑니다.
- Fabric 중첩 모드와 NeoForge/Forge Jar-in-Jar의 선언된 메타데이터를 제한된 크기·깊이로 확인합니다. 해석할 수 없는 의존성은 자동 제거를 막고 경고로 표시합니다.
- 목록은 페이지로 나눠 표시하며 상태 조회 때 전체 모드 메타데이터를 반복 전송하지 않습니다. 모바일 탭과 버튼의 가로 넘침도 보완했습니다.

이번 버전에는 최초 대용량 서버 파일 가져오기의 전송 속도 개선과 Modrinth 검색·설치 UI는 포함되지 않습니다. 이전 0.4.2의 변경 파일만 반영하는 디스크 작업 개선은 포함됩니다.
