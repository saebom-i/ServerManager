## 전체 관리자와 소유자 권한

- 계정과 보안에서 계정 역할을 일반 사용자·관리자·소유자로 지정합니다. 관리자는 현재와 앞으로 추가되는 모든 서버의 생성·삭제·실행·콘솔·파일을 관리합니다.
- 사용자 권한 변경, 전역 보안·연동 자격증명 설정은 소유자에게 유지됩니다. 다른 사람 실행기 업데이트는 기존대로 기기 등록자 또는 소유자만 요청합니다.
- 패스키를 등록한 계정에 소유자 권한을 부여할 수 있습니다. 패스키가 등록된 마지막 활성 소유자는 해제할 수 없으며, 권한 변경 후 대상 계정은 같은 패스키로 다시 로그인합니다.

## 서버별 파일 동기화 ON/OFF

- 실행 컴퓨터 패널에 서버 파일 동기화 토글을 추가했습니다. 기본은 기존과 같은 ON입니다.
- OFF에서는 현재 실행기로 고정하고 시작 전 다운로드·종료 후 업로드·WebDAV 자동 동기화를 생략합니다. 웹 파일 관리자와 저장 로그는 연결된 실행기의 원본 폴더를 직접 읽습니다.
- 파일 조회·텍스트 편집·업로드·다운로드·폴더 생성·이동·삭제를 원본에서 수행합니다. 수정은 서버가 정지됐을 때만 가능하고, 외부 수정 충돌·루트 밖 경로·링크 경로를 차단합니다. 교체·삭제 원본은 실행기에 보관하며 파일 교체 중단 복구를 지원합니다.
- 다시 ON으로 켤 때는 실행기의 최신 원본을 중앙에 반영합니다. 완료하기 전에는 실행기 변경을 허용하지 않습니다. 실행기 오프라인에서는 중앙의 오래된 복사본을 대신 표시하지 않습니다.
- 토글 변경은 서버와 인계 작업이 정지됐을 때 가능합니다. OFF에서는 중앙 복사본 기반 모드 자동 관리·격리 검사를 막으며, 파일 관리자의 mods 폴더에서 직접 수정하거나 동기화를 켜서 검사할 수 있습니다.

## 선택한 실행기에서 서버 설치

- 실행기를 배정한 서버는 NeoForge·Forge·Fabric·Paper·Vanilla 설치를 해당 컴퓨터에서 수행합니다. 관리 Mac에 설치한 후 옮기는 단계가 필요 없습니다.
- 공식 버전·다운로드 해시·필요 Java 검증을 유지합니다. ON에서는 설치 완료 파일을 중앙에 반영하고, OFF에서는 실행기만 보관합니다.
- 기존 사용자 서버 폴더에는 새 설치를 덮어쓰지 않습니다. 기존 폴더 연결 또는 가져오기 기능을 사용하세요.
- **동기화 선택·원본 직접 파일 관리·원격 설치는 중앙과 실행기 모두 0.4.5 이상이 필요합니다.** 구형 실행기는 먼저 기존 자동 업데이트 또는 최신 설치판으로 올리세요. 0.4.4 이상 설치판은 웹의 원격 업데이트 요청도 지원합니다.
