# Server Manager 0.4.6

- Sable 오류 수정: 플레이어 조회(Query)의 UDP 포트를 게임 포트와 분리했습니다. `Received an invalid packet ID: 254` 반복 오류를 방지하며, 명단·절전 직전 조회도 분리된 포트를 사용합니다.
- Sable UDP 공유 중계: 기존 게임 도메인과 포트를 유지하고, 인증된 플레이어별로 올바른 실행기에 전달합니다. 서버 전용 보조 모드는 자동 설치되며 클라이언트 추가 설치는 필요 없습니다.
- 게임 주소·중계 설정에 UDP 토글, 서버 설정에 연결·대체 통신·오류 상태를 추가했습니다. 기존 설치는 기본 OFF입니다.
- NeoForge 1.21.1 + Sable 2.0.6을 우선 지원합니다. 중앙과 실행기를 함께 0.4.6 이상으로 업데이트한 뒤 사용하세요. 다른 조합이나 UDP 연결 실패 시 TCP 대체 통신을 유지합니다.
- 중앙 공유기에 기존 TCP와 함께 **UDP 6399 → 중앙 Mac UDP 6399** 포워딩을 추가해야 합니다. 사용자 지정 공유 포트라면 그 포트의 UDP를 열어주세요. 실행기에는 포트포워딩이 필요 없습니다.
- 중앙↔실행기는 별도 암호화 WSS로 연결합니다. 순수 UDP와 달리 이 구간의 패킷 손실은 지연을 늘릴 수 있습니다. 지연된 패킷을 버리고 큐를 제한해 누적을 방지합니다.

0.4.5의 전체 관리자 역할, 실행기 원본 파일 관리와 실행기 직접 설치 기능을 포함합니다. 계정·패스키·월드와 기존 HTTPS/nginx 설정을 유지하며, 실행 중인 Minecraft는 정상 종료와 파일 인계 후 업데이트합니다.
